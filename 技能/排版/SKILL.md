# 排版：Markdown → 微信 HTML

## 工具
- `工具/md2wechat.py`：读 Markdown，输出内联样式排版 HTML（不依赖第三方、不卡）。

## 用法
从项目根目录运行（venv 已内嵌）：

```bash
./venv/Scripts/python.exe 工具/md2wechat.py 文章草稿/xxx.md
```

→ 生成 `文章草稿/xxx.wechat.html`。

（从 `工具/` 目录运行时：`../venv/Scripts/python.exe md2wechat.py ../文章草稿/xxx.md`）

## Markdown 书写规范（生成前必读，工具兜不了底）

以下规矩工具无法替你兜底——出错不会报错，只会在微信里渲染成乱的、断的或层次乱的。写 md 时必须自己守。

### 必守规矩（工具兜不了底）
1. **第一行 `# 标题` 只作标识**：工具会跳过 `#` 不渲染进正文，但公众号标题栏需要你手动填，别漏。
2. **列表项之间不能空行**：空行会把一个列表断成两截（Markdown 标准行为），工具只能照章办事。
3. **别用工具不支持的语法**：代码块（```）、任务列表（`- [ ]`）、嵌套列表、直接嵌 HTML——都不会正确转换，写出来是乱的。
4. **表格单元格内别用 `|`**：工具没实现转义解析，单元格里出现 `|` 会被当成列分隔符，表格直接错乱。
5. **小节标题统一用 `##` 或 `**加粗**`**：`##` → 18px 加粗标题，`**加粗**` → 正文加粗，混用会导致层次不一致。

### 支持的语法（直接写，会被正确转换）
| Markdown | 效果 |
|---|---|
| `# 标题` | 不进正文，仅作标识（见规矩 1） |
| `## 小节` | 一级小节标题（18px 加粗深色、无橙边） |
| `### 子小节` | 二级小节标题（16px 加粗） |
| `---` | 分割线 |
| `> 引用` | 引用块（多行自动合并） |
| `- 文本` 或 `* 文本` | 无序列表，转成 `• 文本`（项间勿空行，见规矩 2） |
| `1. 文本` | 有序列表，保留原数字手动编号 |
| 表格（列用竖线分隔，第二行横线作分隔行） | 渲染为表格（含表头，长文本自动换行；单元格内勿出现 `|`，见规矩 4） |
| `**加粗**` | 正文加粗（可作小节标题，见规矩 5） |
| `*斜体*` | 斜体 |
| `` `代码` `` | 行内代码 |
| `![alt](url)` | 图片 |
| `[文字](url)` | 链接 |
| 普通段落 | 正文 |

### 文档结构
- 存为 `文章草稿/标题.md`，与生成的 `.wechat.html` 同目录。
- 推荐结构（老杨确认，长期有效）：结论先行 → 表格/测算对比 → 合规提醒 → 红线清单 → 金句收尾 → "个人观点，仅供参考" → PS 预告下一篇。开门见山、去故事化铺垫。

### 微信端要点（重要）
- 列表用纯 `1.` / `-` 写，脚本自动转手动编号段落（微信公众号会忽略 ol/ul 的 CSS 序号）。
- 表格长文本已自动 `word-break`，窄屏不撑破。
- 改稿后重跑 `md2wechat.py` 覆盖旧 `.wechat.html`。

### 风格与合规
- 风格基线见「写作」技能（父亲口吻、平实有阅历、金句收尾、PS 预告）。
- 合规红线：不写"包过核查""保证节税 X%"承诺；政策解读标注"个人观点、仅供参考"。

## 注意
- 排版样式按系列视觉锚点设计（小节标题加粗深色无橙边），**勿手改 HTML**。
- Git Bash 给 Python 传路径用 `D:/...`，**不要**用 `/d/...`（会被误解成 `C:\d\...`）。
- 改稿后重跑此脚本即可刷新 HTML；同篇重跑会覆盖旧 `.wechat.html`。
- 用户侧手动路径见「用户指南.md 第三节」：进 `工具/` 跑 `../venv/Scripts/python.exe md2wechat.py ../文章草稿/xxx.md`。
