# 微信 IP 白名单（40164 处理）

## 触发
- API 调用返回 `40164 invalid ip xxx, not in whitelist`。
- 用户问「当前 IP 是多少 / IP 白名单怎么加 / 为什么 API 用不了」。

## 流程（三步）
1. **查 IP**：运行 `venv/Scripts/python.exe 工具/api/get_public_ip.py`，拿到当前公网 IP。
2. **读 AppID**：从 `工具/api/.env` 读取 `APPID`（自动，无需用户手找）。
3. **拼开发者平台链接**：
   `https://developers.weixin.qq.com/console/product/mp/<APPID>?tab1=basicInfo&tab2=dev`
   （这个链接直接定位到「基本配置」页，省去用户在一堆菜单里找。）

## 告知用户（关键：少让用户自己找）
- 说明现状：API 因 IP 不在白名单失效，**工作流已自动切换浏览器备用方案继续**，本次推送不受影响；
- 建议：把当前 IP 加入白名单，可恢复 API 路径；
- 给**链接（已含 AppID）+ 当前 IP**。

可直接转述的模板：
> 当前公网 IP 是 **`<IP>`**。请打开这个开发者平台链接（已自动定位到基本配置页）：
> `<链接>`
> 在「IP 白名单」点「修改」→ 添加 ` <IP> ` → 保存即可。约 1 分钟生效。

## 提示
- ⚠️ 微信规则：白名单**留空 = 不限制任何 IP**（API 反而可用）；只有白名单填了别的 IP、而当前 IP 不在其中时才报 40164。所以排查时先确认白名单不是"填错 IP"。
- 添加后约 1 分钟生效（微信缓存）。
- 若用户不方便操作，**浏览器备用方案可正常完成推送**，白名单修复不阻塞工作。
