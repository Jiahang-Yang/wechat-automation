# 生成公众号封面

## 触发时机
- 用户说「生成封面 / 配张封面 / 做张头图 / 换个封面」。
- 发布流程（见「发布」技能）需要 `--cover` 封面，但 `素材/` 里没有合适的图。
- 用户想为某篇文章配一张专属封面。

## ⚠️ 必须先告知消耗（必读）
- 调用 ImageGen 会消耗**积分**（约 5~10 积分/张）。
- **调用前必须明确告知用户**，得到同意后再生成；用户不同意则改用已有素材。
- 重新生成 / 微调同样消耗积分，需再次确认（除非用户刚同意且明确要继续调）。

## 微信封面规格
| 用途 | 比例 | 建议 size |
|---|---|---|
| 头条封面 | 2.35:1（900×383） | `1536x1024` |
| 次条 / 小图 | 1:1 | `1024x1024` |

## 调用步骤（ImageGen 是延迟工具，先加载再调用）
1. 用 **ToolSearch** 加载 ImageGen 的 schema（`tool_names=["ImageGen"]`）。
2. 用 **DeferExecuteTool** 调用，参数：
   - `prompt`：中文文生图描述（见下「提示词写法」）
   - `size`：按上表（头条 `1536x1024` / 小图 `1024x1024`）
   - `quality`：`high`
   - `output_dir`：项目根 `素材/` 目录（用**绝对路径**，如 `D:/.../素材`；若工具不支持指定目录，生成后把图移动到 `素材/`）
3. 生成后**确认文件存在**，必要时改名为 `素材/<文章标题>.jpg`。
4. 告知用户：封面已生成 → 文件路径。
5. 推送时用 `--cover 素材/<文章标题>.jpg` 指定（`api_push_draft` 会自动缓存复用该封面，不重复上传）。

## 提示词写法
- 结构：`主体 + 场景/元素 + 风格 + 色调 + 构图`。
- 公众号封面偏好：**简洁、居中、留白、有故事感**；避免杂乱、密集小字、过曝。
- 参考句式：
  「<文章主题>为主题，<画面主体>，<风格>，<色调>，简洁构图居中，留白充足，无文字」
- 示例（财税健康主题）：
  「一位中年从业者在办公室翻阅报表，暖色调，写实插画风，简洁居中构图，留白充足，无文字」

## 不满意时
- 可基于上一张用 `image` 参数做图生图微调（`input_fidelity` 控制与原图相似度），或重新生成。
- 调整前先问用户想要什么方向（换风格 / 换色调 / 换主体），别盲改。
