# 写公众号文章草稿（运海老杨 · 财税健康）

## 账号与内容定位
- 公众号：**运海老杨**（父亲 杨运海），财税健康 / 个人财税 / 从业者视角。
- 强关联书系《财税创造价值》（第一本《财税创造价值：个人财税健康 一位从业者视角》）。
- 核心主张：「懂财税健康的人更值钱、更有价值」。

## 风格基线
- 平实有阅历，像从业 28 年的老财务跟人聊天，不端着、不说教。
- 从**真实场景/故事**切入（客户案例、政策变化、身边小事），再落到观点。
- 金句收尾：结尾一句有分量的话，让人想转发。
- 小节标题：加粗深色、无橙边（视觉锚点，见「排版」技能）。
- 结尾 PS：预告下一篇主题（不承诺具体日期）。

## 合规红线（必守）
- 定位「梳理 / 分享 / 教育」，**不写"包过核查""保证节税 X%"**这类承诺。
- 不针对具体股票、基金给买卖建议（需资质）。
- 涉及政策解读标注"个人观点、仅供参考"，强化教育者人设。

## 选题方向（示例，可扩展）
- 个人财税健康：个税、社保、专项附加扣除、年终奖怎么算
- 小企业主 / 自由职业者：记账、报税、合规常识
- 财税认知：为什么"懂税的人更值钱"、从业者视角的观察
- 政策变化解读：通俗讲清楚"跟你有什么关系"

## 产出位置与格式约定
- 存为 `文章草稿/标题.md`（与排版生成的 `.wechat.html` 同目录）。
- 第一行 `# 文章标题` 仅作标题，**不进正文**（微信标题栏需手填，否则显示两遍）。
- 写好后交给「排版」技能生成 HTML，再交给「发布」技能推草稿箱。

## 写作步骤
1. 确认选题（用户指定 / 结合近期热点 / 从选题方向中选）。
2. 按风格基线写 `.md`：场景切入 → 讲清楚 → 金句收尾 → PS 预告下一篇。
3. 自查合规红线（无承诺、无荐股、有"仅供参考"意识）。
4. 存 `文章草稿/标题.md`，交给「排版」技能。
