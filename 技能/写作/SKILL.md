# 写公众号文章草稿

## 产出位置
- 存为 `文章草稿/标题.md`（与排版生成的 `.wechat.html` 同目录）。
- 写好后交给「排版」技能生成 HTML，再交给「发布」技能推草稿箱。

## 格式约定
- 第一行 `# 文章标题` 仅作标题，**不进正文**（微信标题栏需手填，否则显示两遍）。
- `##` 作小节标题：加粗深色、无橙边（视觉锚点，见「排版」技能）。
- 结尾用 `PS：`写「下一篇预告」钩子。

## 变形金刚同人系列（飞行笔记的一隅）
- 视角：第一人称「惊天雷·书记员」，霸天虎阵营坐角落写战报，毒舌但能被对方人性打动。
- 风格锚点（铁皮篇定调）：小节标题加粗深色无橙边；结尾 PS 预告下一篇。
- **系列衔接铁律（2026-08-05 约定）**：结尾 PS 预告对象**不限于汽车人**，从救护车篇之后转回霸天虎阵营（下一篇 = 大力神）。不要再连续预告汽车人。
- 已发 / 在稿进度以用户后台确认为准（个人订阅号无 API，AI 读不到后台列表，切勿自行推断）。

## 写作步骤
1. 确认承接哪一篇（看用户给的「下一篇」预告）。
2. 按锚点写 `.md`，保持毒舌第一人称、小节标题加粗深色无橙边。
3. 结尾 PS 按铁律预告，注意阵营轮换（汽车人 ↔ 霸天虎）。
4. 存 `文章草稿/标题.md`，交给「排版」技能。
